# WanderMind Travel Product Advisor Framework

Project-local Nuwa theme skill for WanderMind product, route commercialization,
and real-world travel operations decisions.

Status: research checkpoint in progress.

This framework must preserve WanderMind's existing product and visual identity.
It may challenge assumptions, compare operating models, and expose risks, but it
must not impersonate a public figure or replace verified geographic, venue,
driver, pricing, safety, or licensing facts.
