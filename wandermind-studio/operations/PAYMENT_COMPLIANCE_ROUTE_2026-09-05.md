# WanderMind 支付合规路线（2026-09-05）

## 当前定案

WanderMind 当前可售商品只定义为：`数字版巴厘岛专业路线访问权`。商品包含一条数字路线和同一行程的 3 次参数调整；不包含包车、司机、酒店、活动代订或旅行团服务。

当地司机及体验供应商属于独立服务提供者：WanderMind 可以把用户主动提交的需求安全转交给供应商，但供应商应另行报价、说明条款并直接收款。WanderMind 当前不代收交通或活动服务费。

这一定义必须与网站实际界面、订单描述、退款说明及资金流保持一致。不得只改文案而继续代收受监管服务款项。

## 为什么不能把许可证问题当作技术问题绕过

PayPal 中国的 Live 审核已经要求旅行社或出租车/道路运输相关资质。站长没有这些资质时，不提交虚假文件、不借用他人牌照、不把实际交通服务伪报为软件或数字商品。

代码因此新增第二道 Live 门禁：即使误把 `PAYPAL_ENV` 改为 `live` 且已填写 Live 凭据，缺少 `PAYPAL_LIVE_APPROVED=1` 时也不会创建真实订单。该变量只能在支付平台书面确认当前真实商品与资金流可接受，并完成上线检查后配置。

## 服务商结论

| 方案 | 当前结论 | 依据与边界 |
| --- | --- | --- |
| PayPal China | Sandbox 保留；Live 暂停 | 先书面询问“仅售数字路线访问权、不代收交通/代订费用”能否按当前主体开通。平台未确认前不得切 Live。 |
| Paddle | 不采用 | 官方 AUP 禁止旅行服务，并限制以人工服务为主要价值的商品：https://www.paddle.com/help/start/intro-to-paddle/what-am-i-not-allowed-to-sell-on-paddle |
| Lemon Squeezy | 不采用 | 官方规则面向由平台交付的数字商品，并禁止服务类商品：https://docs.lemonsqueezy.com/help/getting-started/prohibited-products |
| Stripe | 当前不采用 | 中国大陆不在直接支持国家/地区清单；不能用虚假境外地址或主体开户：https://stripe.com/global |
| Airwallex | 只做书面预审候选 | 中国主体可申请其全球收款产品，但具体行业、商品、卡收单地区与资金流仍须官方预审：https://www.airwallex.com/cn/payments |
| 印尼本地网关 | 未来阶段 | BCA VA、GoPay、QRIS 通常需要合格印尼主体和本地账户；待真实主体与合作合同成立后再接入。 |

## 站长下一步

1. 向 PayPal 审核团队如实发送：`WanderMind 只向用户出售数字行程路线访问权；不销售或代收出租车、包车、酒店或旅游团费用。当地服务由独立供应商另行报价并直接收款。请书面确认这一商品和资金流是否可使用 PayPal China 跨境收单，以及需要哪些真实材料。`
2. 同时向 Airwallex 做一次书面预审，提交同样的真实商品、网站 URL、中国大陆主体和资金流说明；在对方明确确认前不开发生产接口。
3. 保存平台邮件/工单编号。只有书面通过、费率/退款/争议规则确认、Live 凭据就绪后，才进入生产支付验收。

## 技术门禁

- 当前环境必须保持 `PAYPAL_ENV=sandbox`。
- `PAYPAL_LIVE_APPROVED` 当前不配置或保持空值。
- Sandbox 继续覆盖成功、取消、拒绝、金额不符、重复 webhook、退款人工复核和幂等。
- 前端不接触 Client Secret，不保存卡号；后端创建/捕获订单并核验 webhook。
- 支付成功只授予数字路线权益，不创建司机订单、不承诺供应商库存。

## 中国大陆人工收款路径（2026-09-06 补充）

- 微信与支付宝二维码继续使用现有的“用户提交到账确认、管理员核对后解锁”流程。
- 银行卡转账复用同一人工确认订单，不把真实户名或卡号写入 Git、HTML 或小程序包。收款资料只通过 Render 的 `BANK_TRANSFER_ACCOUNTS_JSON` 保存，并且只对已登录付款用户返回。
- 银行转账附言应填写网站生成的订单号；管理员确认到账前不授予数字路线权益。
- 银联在线支付不是“显示一张银联卡号”即可完成。未完成银联商户入网、接口测试和生产审核前，页面只显示“尚未开放”，不制造可点击但不能支付的入口。
- PayPal 入口继续保留 Sandbox，`PAYPAL_LIVE_APPROVED` 保持空值；这不影响中国大陆用户使用微信、支付宝或已配置的银行卡转账购买数字路线。
- 境外游客查看司机起步估价后，将路线发给 Dicky、Gede Nico 或体验供应商；当地交通与活动由提供者确认最终价格并直接收款，WanderMind 暂不代收。

`BANK_TRANSFER_ACCOUNTS_JSON` 的结构如下。真实值只应直接填入 Render，不能粘贴到聊天或提交到仓库：

```json
[
  {
    "bank_name": "中国银行",
    "account_name": "真实账户户名",
    "account_number": "真实收款账号",
    "branch": "开户行，可选"
  }
]
```
