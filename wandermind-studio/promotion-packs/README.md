## 使用边界

- 两套文件必须分别发送，不能混用链接或图片。
- 每套手册已包含 7 张图片、Instagram Feed、Story、Reels、Facebook、WhatsApp Status、第二组风景轮播文案和常见问题回复模板。
- 01–03 为项目批准的司机/服务图片；04–07 为可公开使用的巴厘岛图库原图。图库作者、来源与许可已写在手册最后一页，发布时必须保留署名。
- 不公开司机私人邮箱、WhatsApp、游客资料或酒店、航班信息。
- 网站估价只是参考；车辆、容量、日期、时长、路线和最终价格仍须由司机确认。
- 本目录只准备材料，不代表已经替司机发布。
