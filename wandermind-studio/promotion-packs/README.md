## 使用边界

- 两套文件必须分别发送，不能混用链接或图片。
- 每套手册已包含 7 张图片、Instagram Feed、Story、Reels、Facebook、WhatsApp Status、两组完整发布文案和常见问题回复模板；建议每 3–5 天发布一次，个人照片不是强制首图。
- 01–03 为项目批准的司机/服务图片；04–07 为可公开使用的巴厘岛图库原图。图库作者、来源与许可已写在手册最后一页，发布时必须保留署名。
- 不公开司机私人邮箱、WhatsApp、游客资料或酒店、航班信息。
- 网站预算器采用 Dicky 亲自提供的初始价格；Dicky 可按天数和路线调整，最终金额以其邮件回复为准。Gede Nico 必须填写自己的价格，不套用 Dicky 数字。
- 本目录只准备材料，不代表已经替司机发布。

站主自己的 Instagram、小红书及首发安排见 `../MARKETING_LAUNCH_PLAYBOOK.md`。
