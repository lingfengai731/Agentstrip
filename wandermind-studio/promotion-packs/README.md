## 使用边界

- 两套文件必须分别发送，不能混用链接或图片。
- 手册已包含 Instagram Feed、Story、Reels、Facebook、WhatsApp Status 和常见问题回复模板。
- 图片来自项目批准清单；不得随意改用互联网图片。
- 不公开司机私人邮箱、WhatsApp、游客资料或酒店、航班信息。
- 网站估价只是参考；车辆、容量、日期、时长、路线和最终价格仍须由司机确认。
- 本目录只准备材料，不代表已经替司机发布。

站主自己的 Instagram、小红书及首发安排见 `../MARKETING_LAUNCH_PLAYBOOK.md`。
