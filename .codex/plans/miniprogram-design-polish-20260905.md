# WanderMind 智旅小程序设计精修计划

## 页面类型与任务

- 主类型：`mobile`，兼具旅行规划、列表、表单与聊天等高频操作界面。
- 受众：用微信在旅途中快速规划、查看路线、比较机酒并联系巴厘岛司机的游客。
- 主路径：选择目的地 → 规划或浏览路线 → 保存行程 → 联系司机。
- 本轮边界：只调整小程序的信息层级、排版、视觉语言、触控与状态表达；不改变登录、支付、路线、司机邮件或接口契约。

## 既有约束

- 保留 WanderMind 的 Travel Paper、Island Teal、WanderMind Amber 与真实旅行工作室气质。
- 保留已通过真机验收的邮箱登录、微信一键登录、错误反馈和现有页面跳转。
- 不把操作页改成营销 Hero，不引入新组件库，不复制其他产品品牌。
- Preview 仅用于验收；本轮不 Upload、不提审、不发布。

## 视觉方向

将当前“白色圆角卡片 + 大量 emoji + AI 宣传语”的模板感，收敛成“随身旅行手册”：纸张底色、细线分组、路线编号和地点信息承担结构；品牌琥珀只标识旅程位置，青绿只标识可执行动作。独特但克制的签名元素是由现有黄色标记演化出的 `WM` 旅行印章，而不是通用 emoji。

## 布局与层级

1. 登录：首页品牌区保持简短；输入、登录、微信登录按一个任务流排列，说明文字降级。
2. 已登录首页：目的地是第一层；“规划、路线、机酒、偏好”是第二层；退出是低频文字动作。
3. 聊天：目的地与模式压缩为工具条；回答正文优先；输入区固定且兼容安全区。
4. 路线/规划：用路线事实与逐日安排形成阅读节奏；保留实际序号，不用装饰性编号。
5. 表单/账户/历史/语言：用细边框和行分隔替代重复悬浮卡片，状态文字与操作保持同轴。

## 字体、色彩与组件

- 中文正文以系统无衬线为主；品牌短标题可保留宋体字形作为有限强调。
- 语义色复用 `DESIGN.md`：琥珀 `#FCBF1E`、青绿 `#0E7C6B`、纸张 `#FAFAF7`、正文 `#2A2723`、边线 `#E5E2DA`。
- 建立最小 spacing/radius/shadow/easing token；页面不得继续散落新的相近色值。
- 按钮统一最小高度、`display:flex`、水平与垂直居中、明确 disabled/loading/pressed 状态。
- 删除作为主要图标系统的 emoji；保留国旗和用户内容中的语义字符，其他入口使用两字短标或统一线性符号。

## 动效

- 高频导航、标签切换和键盘相关动作不做进场动画。
- 仅为按钮按压提供 120–160ms 轻微缩放反馈，为加载点保留必要状态动画。
- 所有位移动效遵循减少动画设置；不增加背景粒子、漂浮光晕或大范围渐变动画。

## 适配与状态

- 以 320/375/390/430 CSS-px 等效微信设备宽度为主，检查长中文、英文、日文、韩文和印尼文换行。
- 控件目标区域至少约 44px；两列在窄屏无法容纳时改为单列。
- 覆盖加载、空、错误、成功、禁用、锁定和已解锁状态；固定底栏不能遮住末尾内容。

## 实施顺序与验收

1. 全局 token、按钮和表单基础层。
2. 首页与聊天两个最高频页面。
3. 路线、规划、机酒比较。
4. 司机、偏好、账户、历史、语言。
5. 契约测试、静态检测、官方 DevTools Preview 编译和真机二维码。

验收标准：所有方框文字水平与垂直居中；无内容遮挡或横向溢出；主次操作在 3 秒内可辨；无新增空按钮；五项已通过的登录验收不回归；机械检测无未解释的 P0/P1；Preview 编译成功但不被描述为正式发布。
