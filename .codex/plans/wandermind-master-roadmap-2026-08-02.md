## 1. 已冻结的产品决策

| 决策 | 当前结论 | 验收口径 |
| --- | --- | --- |
| C1 管理员 | 独立管理员，显示名/用户名为 `admin`。本地开发可用 `123456`；生产密码必须由环境变量注入，不得硬编码进仓库或前端。 | 管理员不受路线收费限制；普通用户不能伪造管理员身份；生产环境缺少强密码时不自动创建弱管理员。 |
| C2 免费额度 | 每次新旅行提供 1 份完整但较粗的 AI 路线，并允许 2 次免费调整；公共目的地与基础信息免费。 | 免费结果能看到完整日程骨架，不采用“后半段遮住”的做法；第三次调整明确提示专业路线或新建旅行。 |
| C3 推荐积分 | 邀请人 +10，被邀请人 +5；30 分可兑换 1 次自动专业路线；注册后 24 小时进入可用状态；每位邀请人每月最多计 5 个有效邀请。 | 防止自邀、重复奖励与立即刷分；积分不可兑换人工定制或司机费用。 |
| C4 专业路线解锁 | 专业路线与 Travel Beans 分离，首发价 ¥9.9；MVP 使用二维码付款 + 管理员人工确认。 | 解锁的是可执行细节：准确顺序、预计车程、到达建议、预约/门票、雨天备选和司机行程单。 |
| 路线体系 | G1–G7 是后台地理事实层；R1–R6 是前台主题产品层。 | 页面不把后台复杂分类直接压给用户；路线必须能追溯到区域、节点和 POI。 |
| 司机报价 | 不编造 Dicky/Gede 的车费；价格状态为待确认，收到真实报价后再发布。 | 司机页和路线页不出现未经司机确认的固定价格。 |
| 图片版权 | 用户自有/获授权素材才可公开；带水印、来源不明、商家官网图片不得直接复制上线。 | 每张上线图片在清单中有来源、授权状态、用途和替代文本。 |

## 2. 圆周旅迹参考：学什么，不学什么

参考来源：

- 官方 App Store 产品页：导入攻略、AI 行程、地图路线、天气交通、多人协作和附近地点。
- 官方行程指南：需求输入 → AI 框架 → 导入收藏内容 → 抽取 POI → 拖入天数 → 地理与交通优化。
- 官方产品截图：移动端地图作为上下文，日程卡片/天数标签作为主要操作面；地点收藏使用地图 + 底部卡片。

### 可迁移的构建方式

1. 用明确任务流替代空白聊天框。
2. 先给完整粗路线建立信任，再出售核验和落地细节。
3. 让用户按“天”编辑、增删和调整地点，不必每次整份重生成。
4. 地图与日程同步高亮，地图用于理解空间关系，不承担全部文字。
5. 把收藏内容抽成结构化 POI；WanderMind 首期先用自己的巴厘岛资料库，导入外部攻略列为后续功能。
6. 移动端采用单列、底部操作区和渐进展开，避免把桌面大面板硬压进小屏幕。

### 必须规避

1. 地图标签拥挤和信息过载。
2. 外部攻略抽取错误、地点过期却不标注核验状态。
3. 只生成通用路线，没有本地可执行细节。
4. 复制其品牌、颜色、组件或宣传素材。
5. 在版权与解析规则未完成前贸然开放全网攻略导入。

WanderMind 的差异化不是“也有一个 AI 聊天框”，而是：

> 巴厘岛专业路线事实库 + 可编辑粗路线 + 已核验执行细节 + 真实本地司机交接。

## 5. 分阶段实施与验证

### Phase P0-A：事实与产品数据底座

1. 建 G1–G7、R1–R6、POI、体验、图片权利清单。
   验证：JSON 结构校验通过；每条路线能追溯到区域与 POI。
2. 建图片收件工具，自动读取文件名、尺寸、哈希、候选分类、地点状态和路线/POI 建议。
   验证：不移动/覆盖原图；重跑和唯一哈希改名不丢人工字段；重复副本不继承批准；只有人工确认、授权状态合格且来源完整的图片进入发布清单。
3. 把用户画像、币种和路线选择定义成统一 trip brief。
   验证：首页、AI、巴厘岛、司机页读取同一 schema。

### Phase P0-B：账户、额度与商业闭环

1. 独立管理员与角色校验。
   验证：本地可测试；生产不接受仓库内弱密码；普通用户越权返回 403。
2. 每次旅行 1 份粗路线 + 2 次调整。
   验证：按 trip 计数而非按聊天句数；管理员无限制。
3. 推荐积分与兑换。
   验证：自邀/重复/月上限/24h pending/幂等均有测试。
4. ¥9.9 订单和管理员确认。
   验证：支付前 locked，确认后 unlocked，重复确认不重复记账。

### Phase P0-C：巴厘岛路线产品

1. R1–R6 路线卡片、动机匹配、按天预览与天序调整。
2. 地图/区域节点联动、同区域 POI 增删和所选日期同步高亮。
3. 免费粗路线与专业细节的清晰差异。
4. 一键把已编辑路线保存为结构化草稿，并导入 AI 或 Dicky/Gede 询价表。

验证：桌面 1440/1280、平板 768、手机 430/390/375/360/320；Chrome、Edge、WebKit；键盘、触屏、深色模式、减少动画和五语言。

### Phase P1：内容、司机与作品集

1. 作品集移位和双层分类。
2. 商家/体验卡片只使用可授权图片与官方预约链接。
3. Dicky/Gede 资料和车辆补齐。
4. README、部署变量、验收证据和回退说明同步。

## 6. 非目标与风险

- 本轮不承诺自动支付、原生 App、全网攻略导入或完整全球目的地内容。
- 不根据模型猜测司机价格、营业时间、评分、医学功效或商家授权。
- Render/Neon/模型供应商属于外部系统；生产变更必须在本地测试通过后独立验收。
- WebKit 自动化不能完全替代实体 iPhone Safari，最终保留真机抽查门禁。
